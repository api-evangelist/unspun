# Unspun

> Unspun is a fashion-technology company building Vega, the world's first 3D weaving machines, which weave yarn directly into finished garments in about twenty minutes for automated, localized, on-demand apparel manufacturing. Backed by DCVC, based in Oakland, California and Hong Kong, it pairs weaving hardware with custom-fit patternmaking and design-automation software for manufacturers and brands. Unspun does not currently publish a public API or developer program.
